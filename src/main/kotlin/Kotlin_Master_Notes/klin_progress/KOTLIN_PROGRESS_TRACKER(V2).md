# 📝 UPDATED LEARNING NOTES & REFLECTIONS

## Key Insights From Today (Coroutines Deep-Dive)
1. **The "cooperative cancellation" gotcha is the #1 real-world bug source** — a `while` loop with no `delay()` or `isActive` check simply ignores `cancel()`. This alone explains a huge % of "why won't my coroutine stop" Stack Overflow questions.

2. **async exceptions are "silent until await()"** — this is the single most-asked coroutine interview trap question. Now mastered.

3. **Flow is cold; Channels are hot** — this distinction is what separates junior from mid-level understanding of reactive Kotlin.

4. **Dispatchers.Main/IO/Default choice is a design decision, not a formality** — picking wrong (e.g., heavy JSON parsing on Main) is a real production bug pattern in Android apps.
